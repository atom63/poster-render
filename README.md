# poster-render

Node.js CLI for rendering poster slides as 1080×1350px PNGs.
Accepts structured JSON or Markdown, outputs one PNG per slide.
Typography, syntax highlighting, background patterns, and cover image support included.

MIT licensed. Issues and PRs welcome.

## Install

```sh
pnpm install
```

Requires Node.js 22+ and native canvas dependencies:

- macOS: `brew install pkg-config cairo pango libpng jpeg giflib librsvg pixman`
- Ubuntu/Debian: `sudo apt-get install build-essential libcairo2-dev libpango1.0-dev libjpeg-dev libgif-dev librsvg2-dev`

## Quick start

```sh
# HTML path — pick a template, get PNGs
poster-render examples/sample-content.json --template minimal --output ./slides

# Canvas path — classic palette-based render
poster-render examples/sample-content.json --palette dark --output ./slides

# Agent pipeline — Markdown in, JSON result on stdout
poster-render deck.md --template bold --json
```

## Templates

Three CSS visual identities for the HTML render path:

| Template | Feel | Background | Accent |
|----------|------|------------|--------|
| `minimal` | Editorial, thought leadership | `#FAF9F6` cream | `#111111` black |
| `bold` | Campaign, product launches | `#111111` dark | `#FF3B30` red |
| `technical` | Engineering blog, devtools | `#0D1117` midnight | `#58A6FF` blue |

```sh
poster-render content.json --template minimal --output ./slides
poster-render content.json --template bold --output ./slides
poster-render content.json --template technical --output ./slides
```

Live preview with auto-reload:

```sh
pnpm preview:minimal   # http://localhost:3456
pnpm preview:bold
pnpm preview:technical
```

## CLI options

```sh
poster-render <input> [options]
```

| Flag | Values | Description |
|------|--------|-------------|
| `--output <dir>` | any path | Output directory (default: `./output`) |
| `--template <name>` | `minimal` \| `bold` \| `technical` | HTML+Playwright render path |
| `--json` | flag | Write `{"slides":[…],"count":N,"template":"…","output":"…"}` to stdout |
| `--palette <name>` | see palettes | Canvas path: override color palette |
| `--spacing <size>` | `sm` \| `md` \| `lg` | Canvas path: override spacing |
| `--typography <name>` | `sm` \| `md` \| `lg` \| `golden-ratio` | Override typography scale |
| `--easteregg` | flag | Enable seeded background remix mode |
| `--seed <value>` | any string | Seed for the easteregg remix |

`--template` and `--json` use the HTML+Playwright path. All other flags use the canvas path.

## Markdown input

Pass a `.md` file directly — no separate conversion step needed:

```sh
poster-render deck.md --template bold --output ./slides
```

For manual conversion:

```sh
node src/markdown-to-content.js examples/sample-markdown.md --output content.json
```

## content.json schema

```jsonc
{
  "template": "default",             // optional; defaults to "default" (legacy alias: boardStyle)
  "theme": { /* see Theme options */ },
  "cover": {
    "title": "Slide title",
    "subtitle": "Optional subtitle",
    "kicker": "Optional top line; auto-generated by default",
    "showKicker": true,                  // set false to hide the top line
    "coverImage": "path/to/image.jpg",  // optional
    "coverStyle": "card"                 // "card" | "fluid" | "inset"
  },
  "sections": [
    {
      "headline": "Section heading",
      "body": "Body text.\n\nSupports multiple paragraphs.",
      "image": "path/to/image.jpg",      // optional inline image
      "imageAspect": "16/9",             // "16/9" | "4/3" | "1/1" | "free"
      "imagePosition": "top"             // "top" | "center" | "bottom"
    }
  ],
  "cta": "Closing call-to-action text",
  "tags": "#hashtag1 #hashtag2"
}
```

Sections are **auto-paginated** — if a section body is too tall for one slide it splits automatically. Sections with images start a new slide.

The cover kicker is generated from deck text as `全文 {字数}字 · {阅读时间}分钟阅读`. Disable with `cover.showKicker: false` or `--no-cover-kicker`.

### Theme options

| Option | Values | Description |
|--------|--------|-------------|
| `palette` | see below | Color system |
| `fontFamily` | `sans` \| `serif` \| `mono` | Base font |
| `spacing` | `sm` \| `md` \| `lg` | Layout density |
| `typography` | `sm` \| `md` \| `lg` \| `golden-ratio` | Text scale |
| `pattern` | see below | Background texture |
| `coverStyle` | `card` \| `fluid` \| `inset` | Cover image treatment |

### Section body syntax

Inline code and fenced code blocks are supported:

````
"body": "Use `const` for immutable bindings.\n\n```js\nconst x = 1;\n```"
````

Supported languages: `js`, `ts`, `python`, `rust`, `go`, `java`, `c`, `cpp`, `html`, `css`, `json`, `bash`, `sql`.

### Custom fonts (optional)

Place `.ttf` or `.otf` files in `./fonts/`. Files are auto-registered by name substring:

| File name contains | Family |
|-------------------|--------|
| `geistmono` | `mono` |
| `geist` | `sans` |
| `helvetica` | `sans` / `Helvetica Neue` |
| `georgia` | `serif` / `Georgia` |
| `menlo` | `mono` / `Menlo` |

For CJK text, install a system font: PingFang SC, Hiragino Sans GB, or Noto Sans CJK SC.
